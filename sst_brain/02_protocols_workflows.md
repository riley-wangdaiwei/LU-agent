# Protocols & Workflows

> 相对静态。公约变了才改，workflow 是成员领任务时的执行手册。

## 团队公约（要点）

- 项目标准周期：**5 周**（旧 brain 写 6 周，以 Operation Manual v2 为准）
- 例会：**双周一次** Zoom，另周群内讨论；会前必须交 pre-meeting report（weekly update + 给他人工作的 feedback + prompt reflection）
- Publish 底线：每月至少 **1 个主线**（深度采访）+ **1~3 个支线**（聊天室、支教、小红书、创意项目）
- 超过 5 次联系不上组员，默认退出项目组；每年每个职位重新决定人选并开放招新

## 内容生产 Workflows

### 采访（主线，每月至少 1 个）

5 周标准周期，3~5 人小组，负责人每月轮换：
1. 第 1 周：联系受访者、定文章大纲
2. 第 2 周：约采访时间、细化提纲
3. 第 3~4 周：整理内容、写初稿
4. 第 5 周：排版发布

方法论（Protocol_I_W"打破偏见"式）：
- 选题：先定一个核心问题（如"健身房为何女性不友好？是幻觉吗"）
- 写小问题：先做案头研究，不问能 Google 到的问题；问题按"审讯"逻辑从易到难
- 采访：聊天式而非问询式，时刻准备追问和质疑，用细节撑起人物
- 写文章：非虚构文学风格——一句话收获 + 真实故事 + 真诚的哲学收尾，忌添油加醋
- 收尾：反思整理归档

**采访嘉宾来源**（2026-09 团队负责人方向：更 creative，不只靠 exec 人脉去约）：
- 与活动结合：线下观赛、校园工作坊、panel、体育节——现场挖掘嘉宾（运动员、教练、组织者、观众里的故事）
- 社区本身就是来源：常读用户、活动参与者里找"正在做运动的普通女性"
- 合作方资源：商业合作中接触到的品牌、学校、组织里的人
- 定位不变：不追知名运动员，挖普通女性的真实故事

### 公众号发布 checklist

视频号同步 → 附往期文章（记得 copy 最新一期）→ 写文章介绍 → 加 hashtag → 原创声明 → 查错别字 → 导到手机上预览。

### 科普文 pipeline

brainstorm 定选题（设 due）→ Research（每人找 3 篇论文）→ Drafting（每人写一段）→ 汇总成稿 → 发布。

### 内容策略（2026-09 内容审计结论）

- 易爆款：热点事件的性别视角评论（Chat#02 单篇 3,977 阅读）、具体小众项目的人物故事（武术 1,864、柔术 1,069）、女性身体/审美议题
- 易被认可：贴近普通女性运动经历的人物故事，近期点赞率超 11%（Talk#25 14.3%、Talk#26 13.0%）
- 高阅读 ≠ 高互动：爆款靠推荐流量，深度内容靠读者认同；派选题时按目标选类型
- 标题规律：高点击 = 具体人物 + 具体项目 + 反差感；高分享 = 争议/设问

### 小红书 / 聊天室栏目（支线）

聊天室栏目连载式（如"全红婵"第 3 期），有固定发布日；小红书还没正式做。

### 内容分发：1 → 5 repurposing 系统

> 详见 Drive「社会项目 / 渠道分发」。一篇原始内容拆成五个平台各自的产品形态，而不是简单剪短。
> 先跑 3 个 pilot series：**LU Stories**（人物，一个故事一个观点）→ IG / TikTok / YouTube Shorts / 小红书；**LU Explains**（知识，60 秒讲清一个问题）→ TikTok / 小红书 / IG Reels / YouTube Shorts；**LU Field Notes**（深度，真研究一个问题）→ Substack / YouTube / IG carousel。
> 原则：不需要先重新采访，先用现有 20+ 篇内容做 30–50 个切片，测试出有效 format 再决定要不要加 production。

### 播客 LU Talk

采访的音视频形态，风格要求"谈话"而非"问询"，由视频剪辑师按项目剪辑。

## 团队角色

- **首席文化官**：价值观落地、团队凝聚、面试新人、年末文化报告
- **项目管理顾问（CPMA）**：定目标/时间线/分工、持续追踪各项目、跨组对齐 ← **这部分活由 agent 接过**
- **出版总监**：美术设计、风格规范、发布前审稿、内容发布日历、网站/社媒
- **荣誉顾问委员会**：卸任 exec，指导 + 知识代际延续
- **普通成员**：项目负责人（谁联系受访者谁当）、视频剪辑师、撰稿人/文章编辑、采访协调员
