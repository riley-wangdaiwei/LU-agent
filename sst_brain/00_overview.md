# SST Brain · 总览

Lady Up 团队的共享大脑，供 LU agent 读取、匹配任务、跟踪进度用。

## 五件套

| 文件 | 内容 | 谁更新 | 更新频率 |
|---|---|---|---|
| 01_longterm.md | 长期计划：愿景 + 1/3/5 年目标 | Riles | 随时想到随时加 |
| 02_protocols_workflows.md | 团队公约 + 内容生产 workflow | Riles / exec | 公约变了才改 |
| 03_active_projects.md | 当前项目 + 排期表 + 状态 | agent（Riles 确认） | 每周 |
| 04_members.md | 成员档案：兴趣 / 空闲 / 资源 | 成员自己（agent 引导填写） | 入职填，变化时改 |
| 05_tracking.md | agent 追踪日志 + 每周追人清单 | agent 自动 | 每周 |

## 设计原则

- 成员档案**低颗粒度**：6 个一句话字段，填完不超过 3 分钟，不给成员增加负担。
- Agent 不代替人做决定：派任务、改排期这类动作先出建议，exec / Riles 点头再生效。
- 有矛盾先标出来问人，不猜。
