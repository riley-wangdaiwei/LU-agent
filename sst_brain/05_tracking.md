# 追踪日志

> agent 自动记。每周一生成"追人清单"给 exec，exec 只做最小动作（转发 agent 写好的提醒）。

## 日志格式

- 日期 / 成员 / 事项 / 状态（进行中 / 已完成 / overdue / 需跟进）

## 每周追人清单（模板）

### 1. 待激活（exec 去推）
- 成员名：agent 写好的一句话邀请，exec 转发

### 2. 任务 overdue
- 成员名 + 任务 + 逾期天数：agent 写好的提醒文案，exec 转发

### 3. 两周无动静
- 成员名 + 上次活跃：agent 建议的 check-in 话术

### 4. 需要 Riles / exec 拍板的
- agent 搞不定的异常：如人员冲突、排期撞车，附建议方案
