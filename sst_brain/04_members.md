# 成员档案

> 设计原则：低颗粒度。6 个字段，全是一句话，3 分钟填完。
> 新成员由 exec 激活后，agent 通过聊天引导填写；信息变了随时找 agent 改一句。

## 字段

| 字段 | 怎么填 | 例子 |
|---|---|---|
| 名字 / 角色 | 名字 + 当前角色 | Selena / Bio Researcher |
| 兴趣标签 | 3~5 个词 | 耐力运动、女性健康、播客 |
| 每周可投入 | 大致小时数 + 忙时段 | 约 3 小时，考试周没空 |
| 资源 / 技能 | 一句话：会什么、有什么 | 会剪辑，有相机 |
| 当前任务 | 正在做的事 | 科普文"耐力"初稿 |
| 状态 | 活跃 / 忙 / 休假 | 活跃 |
